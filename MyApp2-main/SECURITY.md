# Security Policy

Tax Buddy is an educational iOS app that helps first-time filers learn about the federal tax filing process. Because the app discusses taxes, income, SSNs, and bank details, security and privacy should be handled carefully.

## Supported Versions

This project is currently maintained from the `main` branch.

| Version | Supported |
| --- | --- |
| Current `main` branch | Yes |
| Older commits or forks | No official support |

## Reporting a Security Issue

If you find a security issue, please do not post sensitive details publicly in a GitHub issue.

Instead, contact the project maintainer directly through GitHub:

- GitHub profile: [MintyCoder2640](https://github.com/MintyCoder2640)
- Repository: [MyApp2](https://github.com/MintyCoder2640/MyApp2)

When reporting a security issue, please include:

- A short description of the issue.
- Steps to reproduce the problem.
- The file or feature involved, if known.
- Why the issue could affect user privacy, data safety, or app behavior.
- Screenshots only if they do not contain personal information.

## What Counts as a Security Concern

Examples of security concerns include:

- Real personal information accidentally added to the repository.
- Real SSNs, addresses, routing numbers, account numbers, or tax documents.
- Firebase configuration misuse.
- User-entered data being logged or exposed unnecessarily.
- Code that could send more user data than needed to an external service.
- Any vulnerability that could expose private tax or identity information.

## Privacy Expectations

Practice Mode must always use fake data. Do not contribute real names, real SSNs, real addresses, real bank information, or real tax documents.

Real Mode should avoid storing or logging sensitive tax information unless there is a clear, secure reason to do so.

## Tax Advice Disclaimer

Tax Buddy is an educational tool and does not provide professional tax advice. Security reports should focus on app safety, privacy, data handling, and repository exposure rather than disagreements about tax guidance.

## Maintainer Response

The maintainer will review security reports as soon as possible. If the issue is confirmed, the goal is to fix it quickly and update the repository without exposing sensitive details.
